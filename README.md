# Apex SaaS — Pro Landing Template (RAHVEX)

Premium dark-glass SaaS landing page: hero, features, pricing, testimonials, FAQ.
Single HTML file. Edit text, swap links, deploy anywhere.

## Use
1. Extract ZIP → open `index.html` in browser
2. Replace "Apex" texts, links and emails with yours
3. Deploy to Vercel/Netlify/GitHub Pages
